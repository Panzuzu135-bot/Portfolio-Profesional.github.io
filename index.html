Proyectos

ChessTogether

Next.js TypeScript Supabase Expo PostgreSQL

Plataforma social para jugadores de ajedrez que combina mapa interactivo, torneos y sistema de ranking ELO en tiempo real. Los usuarios pueden ver en el mapa quién hay cerca disponible para jugar, crear o unirse a quedadas y torneos, y seguir su progreso con el clásico sistema ELO (K=32).

Desarrollado en equipo como monorepo con Turborepo: incluye app web con Next.js App Router y shadcn/ui, y app móvil con Expo y React Native. El backend usa Supabase con PostgreSQL y PostGIS para consultas geoespaciales, Supabase Realtime para actualizaciones en vivo, y Auth.js v5 para autenticación. La gestión del proyecto se llevó con Linear siguiendo un flujo de trabajo estructurado con issues, specs y pull requests.

CodeOrchester

Electron React TypeScript Rust IA

Aplicación de escritorio para orquestar múltiples agentes de inteligencia artificial desde una sola interfaz. Permite lanzar y gestionar sesiones de Claude CLI de forma interactiva, integrando además la API de MiniMax para combinar distintos modelos de IA en flujos de trabajo personalizados.

Construida con Electron, React y TypeScript para la interfaz, y un backend en Rust para las operaciones de sistema más exigentes. Usa xterm.js y node-pty para emular terminales reales dentro de la app, y Tailwind CSS con Zustand para el estado global. Incluye tests con Vitest y Playwright.
